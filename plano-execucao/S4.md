## Issue #4 — `calcularSemaforo`

Arquivo: `src/server/triage/semaforo.ts`. Função pura, sem I/O, TDD.

**Assinatura (S3 importa — não mude)**:

```ts
export type BandeirasClinicas = { motivoAgudo: boolean; altaHospitalarRecente: boolean; posCirurgico: boolean };
export type EixoSocial = { cuidadorPresente: boolean; zaritScore: number; vulnerabilidades: number };
export type EntradaSemaforo = { bandeiras: BandeirasClinicas; funcional: [number, number, number, number]; social: EixoSocial };
export function calcularSemaforo(e: EntradaSemaforo): { classificacao: "VERDE" | "AMARELO" | "VERMELHO"; pontuacaoJson: object };
```

**Algoritmo v1 (literal da issue — pesos como constantes nomeadas e documentadas)**:
1. Qualquer bandeira clínica ativa → `VERMELHO` direto.
2. Média dos 4 sliders funcionais (0–100, 100 = independência): `< 40` → `VERMELHO`; `< 70` → `AMARELO`; senão passo 3.
3. Eixo social: `!cuidadorPresente || zaritScore >= 12` eleva 1 nível (`VERDE→AMARELO`, `AMARELO→VERMELHO`). Cada vulnerabilidade soma ponto ao score.
4. Saída inclui `pontuacaoJson` completo (bandeiras, média funcional, pontos sociais) para reprodutibilidade.

Testes: os 3 estados, limites exatos (40/70/12), determinismo. (`ponytail:` heurística v1; upgrade = regras configuráveis por escopo.)

## Issue #14 — `elegibilidadePorEscopo`

Arquivo: `src/server/triage/elegibilidade.ts`. Pura, TDD.

**Assinatura (S3 importa)**:

```ts
export type EscopoCER = "FISICA" | "INTELECTUAL" | "VISUAL" | "AUDITIVA";
export function elegibilidadePorEscopo(cid: string, motivo: string, escoposCER: EscopoCER[]): { resultado: "ELEGIVEL" | "NAO_ELEGIVEL" | "REVISAO_MANUAL"; justificativa?: string };
```

**Regras v1 (`ponytail:` lista estática; upgrade = tabela configurável por org)**:
- `FISICA`: G00–G99, M00–M99, S00–T98
- `INTELECTUAL`: F70–F89
- `VISUAL`: H53–H54
- `AUDITIVA`: H90–H91
- CID compatível com ≥1 escopo → `ELEGIVEL`
- CID fora dos mapeados → `REVISAO_MANUAL` (nunca reprovação automática por tabela incompleta)
- CID mapeado mas fora dos escopos do CER → `NAO_ELEGIVEL` + justificativa padrão

Parse do CID-10: letra + 2 dígitos, compare por faixa numérica dentro da letra. Testes: cada escopo, bordas de faixa (ex.: G99/G00, F69/F70), não mapeado, determinismo.
